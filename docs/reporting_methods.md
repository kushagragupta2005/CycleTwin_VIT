# Synthetic reporting methods

The reporting extension reads persisted predictions. It never retrains a predictor, selects a threshold, or changes the immutable raw frozen result. All reported values flow through generated claims.

- **Standard average precision:** sklearn's threshold-grouped, non-interpolated average precision replaces the older rank-by-rank custom statistic in the current development report. Legacy values and intervals remain available. The raw frozen artifact preserves its original definition; the reporting sidecar supplies the corrected statistic. [Pinned-version definition](https://scikit-learn.org/1.6/modules/generated/sklearn.metrics.average_precision_score.html).
- **Reliability / ECE:** equal-width probability bins compare mean predicted probability with generated-event frequency. ECE weights each absolute bin difference by its sample share. It depends on binning and does not establish personal confidence or clinical calibration. The bin count comes from the predeclared frozen protocol. [Calibration reference](https://proceedings.mlr.press/v70/guo17a.html).
- **Calibration diagnostic:** an unpenalized logistic regression of the held-out label on the model logit estimates diagnostic slope/intercept. This is a reporting fit, never a deployed recalibrator. Constant-score subsets have no identifiable slope. Convergence status is reported. Neither coefficients nor subgroup results feed model selection.
- **Decision curves:** net benefit equals TP/N minus FP/N times threshold odds. Flag-all and flag-none references use the same generated labels. Thresholds were predeclared, and none is selected against this curve. These assumed utilities do not establish clinical benefit. [Original decision-curve paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC2577036/).
- **Subgroups:** all records, PMOS-labelled records, safety-gate-passing records and every archetype are reported. These are simulator groups, not diagnosed patient populations or a clinical fairness study. There is no multiple-comparison adjustment; subgroup intervals are descriptive.
- **Intervals:** bootstrap patients, keeping every included cycle from a sampled patient. Score ties are grouped before AUROC/AP calculations. Undefined one-class resamples are excluded only from the affected metric, with the valid-resample count reported. Point counts and all denominators remain explicit. Safety-passing subset intervals condition on that subset, rather than measuring safety effectiveness.

The exact tables are in results_reporting.json and results/reporting_subgroups.csv. The frozen protocol predates reserved-seed generation; later diagnostic computation does not revise the original predictor or its operating choices.
