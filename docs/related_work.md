# Related work

- Teede et al. describe the 2026 consensus name polyendocrine metabolic ovarian syndrome (PMOS), previously PCOS: https://doi.org/10.1016/S0140-6736(26)00717-8. This demo uses the terminology while making no diagnostic claim.
- Teede et al., 2023 International Evidence-based Guideline: https://doi.org/10.1210/clinem/dgad463. The guideline informs the safety-first framing; this demo does not implement diagnostic criteria.
- Lin et al., “Blood glucose variance measured by continuous glucose monitors across the menstrual cycle,” npj Digital Medicine 6, 140 (2023): https://doi.org/10.1038/s41746-023-00884-x. This motivates future exploration of cycle-linked glucose variation; glucose is not evaluated here.
- Collins et al., TRIPOD+AI, BMJ 2024;385:e078378: https://doi.org/10.1136/bmj-2023-078378. See the project reporting checklist.

The project uses a synthetic prospective forecasting setup. It does not claim a clinical comparison, superiority, or novelty.
