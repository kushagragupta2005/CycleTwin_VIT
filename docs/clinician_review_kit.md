# Clinician review kit

This is a 20-minute review of a synthetic research display. It is not a clinical validation session.

## Agenda

| Time | Review activity |
|---|---|
| 0–3 min | Read the synthetic-data, non-diagnosis and withheld-output boundaries. |
| 3–7 min | Review the Kushi doctor view: score, validation context, missingness and abstention banner. |
| 7–11 min | Review the temperature trace, illustrative timing band and generated CGM panel. |
| 11–15 min | Review alert budget, threshold context and confirmatory-assessment prompts. |
| 15–20 min | Capture limitations, unacceptable wording and requirements for future validation. |

## Questions for the reviewer

1. Is the threshold context clear enough to avoid treating the fitted score as a diagnosis probability?
2. Are the abstention rules suitable for discussion, and which are missing?
3. Does the reason banner make withholding understandable without overpromising safety?
4. Which missing input conditions should prevent any display of a personal forecast?
5. Is one alert per synthetic cycle an understandable alert-fatigue constraint?
6. What work-up prompts are appropriate as clinician discussion prompts, and which should be removed?
7. Does the day-band failure remain visible enough in the clinician view?
8. Does the oracle-adjacent EHR-lite disclosure prevent overinterpretation?
9. Which wearable data-quality checks matter before considering a future real-data study?
10. What endpoint and confirmatory measurements would be required for a prospective study?
